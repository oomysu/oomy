# oomy — соцсеть толстых котиков

одностраничная соцсеть: данные живут в браузере (localStorage + зеркало indexeddb), а по желанию — ещё и в бесплатном облаке firebase, тогда мир общий.

## структура

```
index.html          — разметка страниц
css/style.css       — все стили
css/fonts.css       — подключение шрифта manrope
js/app.js           — вся логика
assets/images/      — favicon.svg, logo.svg
assets/fonts/       — manrope (cyrillic, cyrillic-ext, latin, latin-ext), woff2
```

## как выложить на github pages

1. создай репозиторий (например `oomy`)
2. загрузи **содержимое** этой папки в корень репозитория (index.html должен лежать в корне)
3. settings → pages → source: `main` / `(root)` → save
4. через минуту сайт будет на `https://твой-ник.github.io/oomy/`

## общий мир (бесплатный сервер firebase)

без облака у каждого посетителя свой мир. чтобы у всех была одна лента, общие аккаунты и чаты:

1. зайди на console.firebase.google.com (гугл-аккаунт) → «создать проект» (аналитику можно выключить)
2. слева: build → realtime database → «создать базу данных» → регион любой → режим «в тестовом режиме» → включить
3. скопируй адрес базы из шапки (вида `https://имя-...firebasedatabase.app`)
4. зайди на сайт под админом → админ-панель → «☁ общий мир» → вставь адрес → «подключить»
5. друзей приглашай кнопкой «🔗 ссылка для друга» — она даёт ссылку с адресом базы внутри, друг открывает и сразу в общем мире. либо скачай сайт с данными («📥 скачать сайт с данными») — адрес уже внутри файла

обмен живой: изменения долетают за несколько секунд. удалённые записи не воскресают (надгробия). сессии и темы у каждого свои.

## проверка локально

просто открой `index.html` в браузере, или подними сервер:

```
python -m http.server 8000
```

и открой `http://localhost:8000`

## заметки

- без облака аккаунты, посты, чаты, подарки и медиа хранятся в браузере каждого посетителя
- с облаком всё то же самое лежит на firebase (бесплатный тариф: 1 гб хранилища, 10 гб трафика в месяц)
- база в тестовом режиме открыта на запись всем, у кого есть её адрес — не выкладывай адрес публично
- аудио (треки) хранится в indexeddb и через облако не переносится
- шрифт лежит локально, интернет для работы не нужен (кроме gif-поиска, soundcloud-треков и облака)
- админ сайта — аккаунт `@oomy`, он назначается при первой регистрации
